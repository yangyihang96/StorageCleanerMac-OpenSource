# 1.10.1 全功能运行态设计改进

日期：2026-09-14。范围：14 个主功能、设置与权限、6 类小窗。生成方式：内置 GPT Image，21 张逐功能概念图；偏离既有功能的首稿另存，不作为实现依据。

## 设计规则

- 主窗口保留既有深色黄金素材和功能配色。运行状态优先展示当前步骤、真实数值和下一步操作，装饰插图在宽窗口作辅助，窄窗口让出空间。
- 不确定总量只显示活动指示，不能补造百分比。暂停显示暂停符号，停止与失败不能显示成功。实时计数使用等宽数字，路径单行中间省略并保留完整悬停内容。
- 小窗暂停的是自动刷新，提示使用“自动刷新已暂停”；已有手动读取行为保持原样。空图与没有网络读数的区域也识别暂停状态，不使用持续加载的文案或转圈。
- 三级详情的更新采用保留最新内容的节流。暂停后没有下一次采样时，最后一次界面更新仍会显示；立即切换时间范围会撤销旧的待显示内容，避免图形沿用上一项。
- 运行操作区根据实际可见高度布局；主窗口较长内容在独立正文区滚动。小窗二、三级菜单仍是完整单页，不使用滚动。
- 扫描只读，清理、卸载、退出应用、原件处理、硬件写入仍沿用各自原有确认与回读。不为展示运行状态而执行破坏性操作。
- 概念中的数据、取消能力、权限类别和硬件支持不作为产品事实；以现有 Store 和服务能力为准。
