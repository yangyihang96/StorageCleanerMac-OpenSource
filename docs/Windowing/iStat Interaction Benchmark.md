# iStat Menus 小窗交互黑盒对标

## 范围与方法

- 观察日期：2026-08-11（Australia/Sydney）。
- 被观察应用：`/Applications/Setapp/iStat Menus.app`。
- 方法仅限启动应用、鼠标移动/点击、键盘输入、屏幕观察、公开的 Core Graphics 窗口边界与时间戳记录。
- 未反编译、注入、Hook、读取私有实现、提取资源或复制视觉素材。
- 当前机器只有一块可用显示器：`frame = (0, 0, 1352, 878)`，`visibleFrame = (0, 71, 1352, 778)`，缩放倍率 2x。
- 计时由外部点击辅助程序和窗口轮询完成，包含进程调度与轮询开销，只能作为用户可感知延迟的近似值，不能解释为 iStat 内部常量。

## 对本项目的可用结论

1. 快速扫过不应触发内容闪换；项目采用 120 ms 首次打开延迟和 90 ms 切换延迟。
2. 轻微移出不应立即关闭；项目采用 260 ms 普通关闭延迟。
3. 父项、子面板和间隙应作为一个连续交互组；项目使用 8 pt 扩展的几何安全通道，通道只参与命中计算，不创建透明拦截窗口。
4. 明显远离目标时不需要过度粘滞；项目将反方向关闭缩短到 90 ms，朝目标移动或进入安全通道时延长到 320 ms。
5. 主面板必须跟随真实状态项屏幕坐标，而不是固定在 `NSScreen.main` 的某个角落。
6. iStat 的外部点击关闭非常直接；项目继续保留既有的外部点击关闭，并让 Esc 按层级先关闭最深面板。

这些参数是依据本轮可观察行为和任务给定范围建立的首版策略。由于 iStat 本次没有展示独立父子级联窗口，项目的级联翻转、安全通道、多显示器和 Dock 适配以自身纯几何测试与真实运行验证为准，不宣称复制了 iStat 的内部算法。
