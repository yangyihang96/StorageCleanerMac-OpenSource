## 已实施的生产链路

### 安全、回执、隐私

- 合法 MAD=0 可用，零/负/非有限原始速度或延迟仍拒绝。
- 卸载必须有扫描身份，复核词法路径、链接、运行状态、Bundle ID 和版本；扫描/移动/恢复统一包含 birth time 的身份合同。不用显示名或猜测共享容器归属。精确 ID 目录仍只是候选，没有独占证据则保留。
- Release 曾误拒绝合法 ID，改为 Apple CFBundleIdentifier 的 ASCII 字符规则，补优化构建回归。低 App Store 评分不自动推荐卸载，未知使用时间不当成从未使用。
- 现有 CleanReportStore 增加持久化意图与逐路径结果。旧清理单项多路径和 App 卸载接入 RecordedTrashOperation。A 成功/B 失败、日志失败、取消不丢已移动回执；在途调用结束前不释放租约。
- 完整 Release v4 抓到网络兼容测速取消的时序失败（1 项）；不是忽略后重试。根因是 `invalidateAndCancel()` 可能立即发送失效回调，不能证明任务排空。改为先取消各任务，再 `finishTasksAndInvalidate()`；保留原停止计数和租约断言。官方依据：[URLSessionDelegate](https://developer.apple.com/documentation/foundation/urlsessiondelegate/urlsession(_:didbecomeinvalidwitherror:))。修复后结果见 network-drain 与后续全套日志。
- 2026-09-20 补齐新清理、重复文件、操作中心的逐项恢复写前日志与结果持久化；恢复使用原子不覆盖移动，保留原清理和每次恢复历史。日志失败停止后续移动；中断结果按源/目标身份核实，旧界面优先读取持久记录。旧 TrashMoveRecord 恢复入口仍另列待统一。
- 单个损坏回执不隐藏其他有效回执。中断 Trash 调用可在持锁条件下按唯一完整身份核实，操作中心展示结果与冲突；恢复不覆盖已存在目的路径。
- App 外接迁移现在复制后保留原件。复制前登记专属 staging；清理仅限本任务资源，失败留残留记录。完整内容绑定的原件移走能力尚未实现。

### M 系列 Core 与产品入口

- 新 Core18 接入现有 App、Store、重任务协调器及历史仓库。CPU 单/多线程 integer、floating、LZFSE compression、image；Metal 离屏、FP32、FP16；memory copy、triad、pointer chase；storage 顺序读写和 4K QD1 随机读写，全部有真实内核。
- 固定生成素材、预热不计分、三轮样本全部保留、输出正确性验证。多线程使用全部实际逻辑核心，不按型号加分、不减一/封顶 64。指针追逐验证完整排列和全部链接。
- GPU 用 command-buffer GPU 时间，不受显示器刷新率控制。读盘校验不计读取耗时，但计安全期限；写入请求 F_NOCACHE，fsync 在写入计时内。正常总写入 336 MiB，会话预算 512 MiB，失败重试不能重置预算。
- 能力来自 native ARM64/Rosetta、实际核心层级、Metal 和资源查询。没有芯片代际白名单。未知/不支持/资源不足/失败/未实现为不同状态；部分 API 失败分类仍需细化。
- CPU 线程曲线及约 6 秒、最多 12 批次短持续观察已接入。扩展环境独立，不回溯污染 Core 环境。
- 跑分临时文件创建前写入原操作回执，清理后核销；保留未知资源和清理失败残留，已有独立 fixture 回归。
