## 3. 硬件能力门

`HardwareFanCapabilityProbe` 需要：

- 至少一个真实风扇读数；
- 每个风扇的名称、当前 RPM、最小 RPM、最大 RPM 和目标 RPM；
- 所有风扇都有有效且完整的可写范围；
- trusted privileged helper 可用；
- 可用温度传感器；
- 当前控制模式。

只有上述条件满足，`supportsWriting` 才为 true。风扇缺失、范围不完整或 helper 不可信时，自定义/手动/最大模式隐藏。

## 4. 当前安全机制

| 机制 | 当前代码合同 |
|---|---|
| 范围夹紧 | 目标永远限制在每个风扇硬件报告的 min/max |
| 狂暴模式 | 使用每个风扇自己的 maximum RPM，不写任意夸张数字 |
| 更新间隔 | 至少 2 秒 |
| 变化速率 | 最多 500 RPM/s |
| 曲线滞回 | 温度锚变化达到 2 °C 才更新曲线输入 |
| macOS thermal floor | 请求值不足以比当前系统转速高至少 120 RPM 时，释放该风扇回系统控制 |
| 降速授权 | 只有结构化请求明确标记的“手动转速”模式允许低于 helper 写入时读到的实际 RPM；曲线和预设仍是只增不降的 cooling overlay |
| 热状态 | serious/critical 直接生成 restoreAll |
| helper watchdog | apply 请求为 8 秒 watchdog |
| 写后反馈 | 按风扇保存最早未验证目标与起点；连续写入不会续期；12 秒后检查实际 RPM；容差为 max(300 RPM, 目标的 10%) |
| 回包完整性 | coordinator 拒绝缺失、多余、越界或不等于请求值的 applied target，并恢复系统控制 |
| 失败恢复 | 缺读数、写入失败、回读未达标、XPC 中断时 fail closed，并最多重试三次 restoreAutomatic |
| 生命周期 | 应用终止、系统睡眠、session resign active 和关机通知触发 restoreAutomatic |
| 重启安全 | manual / maximum 不从偏好恢复为活动模式；初始化时回到 systemAutomatic |

这些是代码和 planner 测试合同。没有真实 helper/watchdog 进程和风扇硬件写入证据时，不能写成“故障恢复已实机通过”。

## 5. 曲线编辑合同

当前曲线支持：

- 同步全部风扇或分风扇配置；
- 添加、删除、拖动/修改控制点；
- 恢复默认；
- 30…105 °C；
- 最多 8 个点；
- 温度严格递增至少 1 °C；
- 速度 fraction 单调不下降并限制在 0…1；

缺少真实传感器或风扇范围时，planner 返回 nil 并恢复系统控制，而不是使用 fixture 温度。

三级控制入口在没有可用温度传感器时隐藏“自定义风扇曲线”，并明确提示该限制；若风扇读数或 min/max 范围不完整，则仅保留监控/自动控制入口，不显示假写入模式。

## 14. build 2026080505 helper 硬崩溃恢复边界

- 根因补强：helper 原先只在 XPC 正常失效或进程仍存活时依靠
  `invalidationHandler` / watchdog 恢复。若 helper 被 SIGKILL 或硬崩溃，
  `forcedFanIDs` 和 `watchdogDeadline` 会随进程丢失，下一次启动没有恢复依据。
- 最小修复：第一次可能切入手动控制前，受信任 helper 在
  `/var/run/com.local.StorageCleanerMac.FanControlHelper.active` 写入自己的
  crash-recovery marker；成功恢复所有风扇后删除 marker。helper 启动若发现 marker，
  先执行 `restoreAllFans()`，恢复失败则退出且不接受 XPC，避免在未恢复时显示或执行写入控制。
  没有 marker 的普通启动不访问 AppleSMC 写入路径。
- 追加 `FanControlPackagingTests.testHelperArmsCrashRecoveryBeforeWritesAndRecoversOnLaunch`，
  验证 marker 在首个目标写入前建立、启动先恢复、恢复失败退出和成功恢复清理 marker。
- 本轮没有启动 helper、创建 marker、申请管理员权限、安装 helper 或向真实风扇写入 RPM；
  marker/启动恢复和 watchdog 仍需真实 Developer ID/SMAppService 现场验证。
