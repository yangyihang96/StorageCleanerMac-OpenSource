# v6 容量公式修复前的失效校准记录（2026-07-17）

这里原样保留一段 `session-1` 的 4 次 Standard v6 Release 跑分。四条记录均通过当时的单次稳定性门禁，但随后交叉审查发现：当时客户端的 `usesCapacityAwareScoring` 只匹配 v5，导致 v6 综合指数没有按产品要求纳入内存容量与系统盘容量。

这些 JSON 仅作为“真实数据通过旧门禁但公式不符合需求”的审计证据，不属于生产基线或社区排行榜。
