# Storage Cleaner Mac v1.4.0 Master Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Coordinate the independently testable v1.4.0 performance, health, privacy, menu-popover, and release plans into one verified public release.

**Architecture:** Execute five bounded plans in dependency order. Performance foundations land before new stores and views; health and privacy can then proceed independently; menu integration consumes their cached summaries; release validation begins only after every subsystem has passed its own tests.

**Tech Stack:** Swift 6, SwiftUI, AppKit, SwiftPM, IOKit/Foundation, SQLite3, Sparkle 2.9.4, zsh release tooling, GitHub CLI.
