# Storage Cleaner Mac v1.4.0 Performance Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the known main-thread and repeated-rendering hot paths before adding v1.4.0 health, privacy, and menu content.

**Architecture:** Introduce deterministic presentation snapshots, defer icon work outside SwiftUI body evaluation, load persisted histories after first launch frame, and consolidate the two menu refresh state machines behind one policy. Preserve the existing separated navigation and menu monitor states.

**Tech Stack:** Swift 6, SwiftUI, AppKit, Swift Concurrency, XCTest, SwiftPM.

**Test fixture convention:** Every helper named in a test snippet (including `makeEnergyApp`, `RecordingHistoryLoader`, and `.fixture`) is a private helper implemented in that same test file as part of the task; it is not assumed to exist in production code.

- [ ] **Step 3: Add the minimal model**

Move `EnergyImpactSortMode` out of the private view scope and add:

```swift
struct EnergyImpactListPresentation: Equatable {
    let apps: [EnergyImpactApp]
    let maxEstimatedEnergyWh: Double
    let maxCurrentPowerWatts: Double
    let maxAveragePowerWatts: Double
    let lastID: String?
}

enum EnergyImpactListPresenter {
    static func presentation(
        apps: [EnergyImpactApp],
        query: String,
        sortMode: EnergyImpactSortMode
    ) -> EnergyImpactListPresentation {
        let term = query.trimmed
        let filtered = apps.filter(\.isApplication).filter { app in
            term.isEmpty
                || app.name.localizedCaseInsensitiveContains(term)
                || app.sourceTitle.localizedCaseInsensitiveContains(term)
                || app.path.localizedCaseInsensitiveContains(term)
        }
        let sorted = sortMode.sorted(filtered)
        return EnergyImpactListPresentation(
            apps: sorted,
            maxEstimatedEnergyWh: max(sorted.lazy.map(\.estimatedEnergyWh).max() ?? 0, 0.001),
            maxCurrentPowerWatts: max(sorted.lazy.map(\.currentPowerWatts).max() ?? 0, 0.001),
            maxAveragePowerWatts: max(sorted.lazy.map(\.averagePowerWatts).max() ?? 0, 0.001),
            lastID: sorted.last?.id
        )
    }
}
```

In `EnergyImpactView.body`, create one local `presentation` from `snapshot.apps`, `searchText`, and `sortMode`; use it for count, empty state, `ForEach`, maxima and divider checks. Remove `visibleApps` and the three computed maxima.

- [ ] **Step 3: Implement bounded deferred loading**

`CachedAppIconView` renders a symbol immediately, then starts a `.task(id: path)` that asks the cache for an icon. The cache deduplicates paths and caps retained images; no view body calls `FileManager.fileExists` or `NSWorkspace.icon(forFile:)`.

```swift
struct CachedAppIconView: View {
    let path: String
    let size: CGFloat
    @State private var image: NSImage?

    var body: some View {
        Group {
            if let image { Image(nsImage: image).resizable() }
            else { Image(systemName: "app.fill").resizable().symbolRenderingMode(.hierarchical) }
        }
        .frame(width: size, height: size)
        .task(id: path) { image = await AppIconCache.shared.icon(for: path) }
    }
}
```

Replace all five audited inline icon/file-existence call sites with this component.
