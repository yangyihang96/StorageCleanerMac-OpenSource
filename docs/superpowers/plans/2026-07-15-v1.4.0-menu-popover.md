# Storage Cleaner Mac v1.4.0 Menu Popover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a compact and a stable high-density menu-bar panel with real CPU/GPU, memory, disk, network, sensor, fan, power, battery and cached health data.

**Architecture:** Keep the compact popover unchanged in size, decompose the advanced popover into section files sharing visual primitives, and replace the disappearing nested mode menu with an inline segmented control. Consume `ComputerHealthStore.menuBarSummary`; no menu view may invoke health commands or network tests.

**Tech Stack:** SwiftUI, AppKit menu-bar popover integration, existing SystemMonitorService telemetry, ComputerHealthStore cache, XCTest.

**Test fixture convention:** Every `.fixture` value referenced by a test snippet is implemented privately in that test file as part of the task; no fixture-only API is added to the shipping target.
