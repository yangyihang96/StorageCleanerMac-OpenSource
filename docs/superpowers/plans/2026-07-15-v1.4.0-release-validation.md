# Storage Cleaner Mac v1.4.0 Release and Validation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the v1.4.0 implementation in a real installed build, publish versioned source and updater releases, complete an actual Sparkle upgrade from 1.3.1, and remove development artifacts without touching protected user files.

**Architecture:** Treat source verification, installed-runtime verification, packaging, GitHub publication, updater publication, and Sparkle replacement as separate proof states. Keep the canonical app name `存储清理助手.app`, derive every public asset name from one version source, and retain Apple Development versus Developer ID notarization as an explicit release limitation.

**Tech Stack:** SwiftPM, zsh, codesign, hdiutil, Sparkle 2.9.4, Git, GitHub CLI, curl, AppKit/SwiftUI runtime inspection, macOS Activity Monitor/ps/sample.
