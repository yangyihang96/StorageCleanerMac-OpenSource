# PureMac 功能对照与 2.0.0 Beta 整合记录

对照来源：`momenbasel/PureMac`，源码 `fffc7d9616c4a686ff6a92ef8480cf9da793e384`；安装包为官方 v3.0.0 DMG，下载 SHA-256 `b962b9c49c3eba506f07b5edd6cd17be68345b3cc6a6a0b7af020165ea2a69bc`。本轮阅读 README、中文说明、相似照片和防护审计实现，并使用其官方截图作功能对照。没有复制 PureMac 源文件或素材。

| PureMac 功能 | 本项目生产入口与本轮处理 |
|---|---|
| 应用卸载及关联文件 | 已有 App 卸载；保留身份复核、共享容器保护及恢复回执，不移植名称启发式删除。 |
| 孤立文件查找 | 已有残留启动项检查；未有可信的全 `~/Library` 孤儿归属判断。此轮不把“未匹配到已装 App”当作可删除证据。 |
| 智能清理、缓存、邮件、开发工具、废纸篓 | 已有对应扫描或只读定位；不引入无人值守删除、强制清空废纸篓、私人 AI 历史清理。 |
| 空间浏览与大文件 | 已有文件分析、大文件入口；不建平行历史库。 |
| 精确重复文件 | 已有 SHA-256 确认、保留副本和清理前复核。 |
| 相似照片 | 已有本地图像指纹候选筛选；本轮新增并排缩略图、原件预览和访达定位。候选仍不可进入安全清理。当前筛选较保守，不能宣称覆盖 PureMac 的全部视觉近似范围。 |
| 防护检查 | 原有 FileVault 与备份；本轮在现有健康页加入按需读取 Gatekeeper、应用防火墙、SIP 和 XProtect 本地组件。读取失败显示未知；XProtect 组件存在不等于防护运行或完成恶意软件扫描。 |
| CPU、内存、启动项和本地快照 | 原有性能监控及启动项检查、Time Machine 状态；未增加快照删除。 |
| 应用更新 | 已有 Homebrew 与其他来源的更新入口；保留现有来源验证。 |
| 定时自动清理与 CLI 永久删除 | 不整合自动破坏性操作；与本项目明确确认、逐项回执和恢复边界不符。 |

本轮所有新增操作只读。测试只用临时夹具，没有扫描或删除用户私人文件。PureMac 的 MIT 许可允许参考设计；若以后复制其源码或素材，应将对应版权和许可正文加入第三方声明。
