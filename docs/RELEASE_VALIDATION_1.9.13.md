# 1.9.13 本地发布验收

版本：1.9.13；Build：202609120014；基线：v1.9.12。

本记录区分源码回归、实际运行、签名归档和公开发布。原 49 项黄金视觉验收不由本次测试结果代替。

## 本轮发现与修复

Release 测试最初无法编译：部分测试直接引用只在 Debug/Beta 编译的截图管线、演示数据与只读硬件 fixture。修复为与被测工具一致的编译条件；混合测试只限定 fixture 断言，文件迁移、安全阻断等正式逻辑仍参与 Release 测试。原生风扇控制面板的布局测试改用测试内自建的值快照，继续在两个配置中运行。没有把演示工具或模拟硬件写入路径加入正式应用。

正式包实际启动时还发现资源清单遗漏：13 张 Beta 已使用的现有插图没有复制进 Release，页面退回旧插图。已补齐打包清单，并在每个解包/挂载后的应用中逐文件比对源资源。资源修复只重新封装并签名已验证的优化二进制；本地记录保留复用二进制指纹、完整生产校准日志与重新归档日志。未把缺素材的候选包用于发布。

## 验证状态

- 冻结源码后的 Debug 全量复验：2791 项，17 项显式启用/硬件测试跳过，0 失败。
- 生产校准门：34 项通过。
- Release 全量：2743 项，17 项显式启用/硬件测试跳过，0 失败。
- 真实官方性能流程：运行 416 秒后返回 preflightBlocked。CPU、GPU、内存、存储和显示产生 26 项指标，83/84 次工作负载执行完成（最后一次持续阶段失败）；持续阶段因 thermalNotNominal 在起步前安全中止，未完成 600 秒测试，不能记为完整官方成绩。本机同时运行其他高负载任务，未结束其他任务，也未绕过温度保护。
- 最终中英文 DMG/ZIP：元数据、arm64/macOS 14、严格应用及 Helper 签名、资源逐字节一致性、归档校验和 SHA-256 均通过。最终 ZIP 为 34228526 字节；现有应用专用 Keychain 账户完成 Sparkle EdDSA 签名，并以嵌入公钥通过独立 CryptoKit 验证。
- 排行榜服务端：本机锁定依赖安装后，100 项测试及 TypeScript 类型检查通过。没有部署或修改远端数据库。
- GitHub CI、CodeQL、Release candidate verification 已停用；三个工作流仅保留 workflow_dispatch，不由 push、tag、pull request 或 schedule 触发。Dependabot 的依赖管理设置未改动。

## 运行与诊断边界

发布前检查用户与系统 DiagnosticReports：现存匹配报告为 22 个资源诊断及 3 个历史 spin 报告，没有匹配的 .ips/.crash。最近的资源报告属于旧 Beta build，标注 CPU 或磁盘写入、Action taken: none，不能等同于本版崩溃。最终包已实际启动并切换主页面、隐私、性能历史和明暗外观；旧版历史仍可读取，外观恢复跟随系统。关闭主窗口后的 30 秒观察进程存活，CPU 时间增加 1.72 秒（单核口径约 5.73%，当时存在其他任务和后台应用清单扫描，不作为空闲基准）。截至运行后回读，匹配诊断文件无新增、无新的 .ips/.crash。此检查不保证其他设备或未来运行永不崩溃。
