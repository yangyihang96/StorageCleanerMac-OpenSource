# UI 2.0 规范：视觉、自适应、动效（D53）

状态：v1.1，2026-10-07 下午。V0 批按此实现。断点已按自适应审计（`StorageCleanerMac-evidence/round2/ui-v2/audit-responsive-20261007.md`）校准，改动记在文末“变更记录”。

## 0. 为什么重做

用户（2026-10-07 下午）：“当前软件的 UI 界面还是太丑了。而且你需要适配多种情况的 UI，比如当窗口变大或变小时，UI 也要考虑到这种情况去做相应的改变。然后，把动画效果都给我做好。”

现状诊断依据：
- 实机截图 `round2/live/shots-20261007/`；
- U1 批离屏截图 `.sc-build/r2-u1-preselect/shots/`；
- 49 张黄金效果图 `artifacts/concept-comparison-20261001/references/`。

1. **夜间是纯黑平面**：画布与卡片几乎同色，没有层次与光感。效果图则是深靛蓝底、柔和光晕、半透明卡片、渐变图块和渐变圆环。
2. **页头没有统一规则**：内存页的大图块、超大标题和零散小插画占去约 1/4 高度，可操作列表只露出一行；文件分析的页头又是小线条图标。
3. **颜色无章法**：同一页里混用绿色主按钮、紫色分段和蓝色图表；灰底白字按钮对比不足。
4. **组件形态陈旧**：默认分段控件、细线单色圆环、无填充折线、方块勾选框；矩形图各块同色。
5. **侧栏**：裸线条图标，颜色杂；滚动后首项被压在标题下。
6. **几乎没有动效**：切页、扫描、结果出现、数值变化、勾选、展开都是硬切。全仓 `matchedGeometryEffect` 0 处、`symbolEffect` 0 处、`contentTransition` 2 处。
7. **尺寸适配零散**：71 处 `ViewThatFits`、54 处 `GeometryReader` 由各页各写。900×640 下性能页和分栏视图被裁；1280 宽以上出现大片空白。

## 1. 视觉语言 v2

### 1.1 底色主题

夜间默认为**“深空”**（D56：用户看过 V0 中途样张后选定）。纯黑保留为可选项，也要做出层次：加光晕、渐变图块、带描边的卡片。

| 令牌 | 纯黑（可选，重做层次） | 深空（夜间默认，D56） | 日间象牙白（C2-4） |
|---|---|---|---|
| canvas | #000000 | 线性渐变，上 #10162E → 下 #0A0E20 | #F0ECE2 |
| sidebar | #050505 | #0B1022 | #F7F0E6 |
| card | #111214 | #161D3B，不透明度 0.88 | #FBF7EF |
| cardElevated | #17181B | #1B2347 | #FFFDF8 |
| cardStroke | 白 8% | 1 pt，竖向渐变 白 10% → 白 3% | 黑 6% |
| divider | 白 8% | 白 7% | 黑 7% |
| textPrimary | #F2F2F4 | #EEF1FA | #1F1B16 |
| textSecondary | #A1A1AA | #A3ABC6 | #6B6358 |
| shadow | 无 | 无（靠描边与光晕） | 黑 6%，y 2，模糊 10 |
| moduleGlow | 模块色 12% | 模块色 16%，右上径向，半径约为详情区宽的 60% | 模块色 10% |

- “设置 › 底色主题”同时提供深空（默认）与纯黑；已选过纯黑的用户保持原选择。
- 打开“降低透明度”：卡片改为不透明，玻璃改为实底。
- 打开“增强对比度”：描边加深到 白 20%／黑 18%，次要文字提亮一级。
- 对比度下限：
  - 正文、按钮白字、次要文字 ≥ 4.5:1；
  - 三级说明文字 ≥ 3:1。
  - 每处颜色改动都附取色值与对比度。

### 1.2 模块色与渐变

- 模块与颜色的对应关系不变（D3、D44①），只调色值。
- 每个模块配一对渐变色：亮端（左上）为基色提亮约 12%，暗端（右下）为基色压暗约 10%。
  - 夜间用亮版基色。
  - 日间用 U2 起点值：橙 #C44A16、琥珀 #A85E0C、粉 #D6266E、紫 #4E32BF、青 #0E7C8C。蓝、绿按同样的对比要求取值。
- 模块色只用在以下地方：
  - 页头图块；
  - 主按钮；
  - 选中态（侧栏、分段控件、勾选框）；
  - 本页图表的主序列；
  - 页面光晕。

  正文、次要按钮、背景不用模块色。
- 风险语义色独立于模块色：成功用绿，警告用琥珀，危险用红。
- 破坏性操作一律用危险渐变，不用模块色，包括退出应用、移到废纸篓、清理（承接 N19、D49）。

### 1.3 字号

| 角色 | 规格 |
|---|---|
| 页标题 | 26 pt 粗体；紧凑页头 20 pt 半粗 |
| 副标题 | 14 pt 常规，次要色 |
| 分区标题 | 15 pt 半粗 |
| 正文 | 13 pt；次要 12 pt；说明 11 pt（最小值，不再更小） |
| 指标大数 | SF Pro Rounded 半粗，等宽数字；主指标 36–40 pt，卡片指标 22 pt |
| 侧栏 | 13 pt 常规，选中项半粗；分组标题 11 pt 半粗，字距 +0.3 |

只用四种字重：常规、中等、半粗、粗体。

### 1.4 间距、圆角、层次

- 间距按 8 pt 栅格取值：4／8／12／16／20／24／32／40。
- 页边距：紧凑 16，常规 24，宽 32。
- 卡片内边距：紧凑 12，常规 16，宽 20。
- 卡片间距：紧凑 12，其余 16。
- 圆角（全部用连续圆角）：

  | 元素 | 圆角 |
  |---|---|
  | 页头卡 | 24 |
  | 卡片 | 18 |
  | 内嵌块 | 12 |
  | 列表行 | 10 |
  | 按钮 | 12（大按钮 14） |
  | 图块 | 边长的 28% |

- 只有三层：画布 → 卡片 → 卡片内嵌块。不允许卡片里套卡片再套卡片。

### 1.5 组件

新增或重写，放在 `Views/DesignSystem/`。

- **`PageHero`**：取代 `ModulePageHeader` 的外观。包括图块、标题、副标题、右侧操作区，以及可选的插画槽。尺寸规则见 2.3。
- **`IconTile`**：模块渐变底加白色 SF Symbol，顶部带一道高光。尺寸 22（侧栏）、32（列表行）、52／64（页头）。
- **`SurfaceCard`**：卡片底、描边、日间阴影，可选悬停抬升。
- **`GradientButtonStyle`**：
  - 种类：
    - 主操作：模块渐变；
    - 危险操作：红色渐变；
    - 次要：模块色 14% 填充加模块色文字；
    - 幽灵：无底。
  - 高度 32／40／52。大按钮左侧可带图标块，即效果图里“开始扫描”的样式。
  - 状态：悬停提亮 6%，按下缩放到 0.97，禁用时不透明度 0.4。
- **`MetricRing`**：角度渐变描边、圆头，轨道不透明度 12%，夜间加外发光；中心数值用数字过渡。
- **`TrendChart` 外观**：2 pt 平滑曲线，面积渐变填充（35% → 0%），网格线为白或黑 6%。
- **`CapsuleSegmentedControl`**：模块色选中块，切换时滑动。取代页内的默认分段控件（D44、U2）。
- **`AnimatedCheckbox`**：模块色或危险色，勾选时缩放并描出勾线。
- **`PinnedActionBar`**：贴底操作条。macOS 26 及以上用 `glassEffect`，以下用 `.ultraThinMaterial`。左侧是已选摘要，右侧是主操作。
- **`StatusFooter`**：效果图里的页脚信息条，例如“尚未扫描 | 只读扫描 · 清理前逐项确认”。
- **`SkeletonBlock`**：加载时的占位块，带一道扫过的微光。
- **插画**（`GoldenLandingArtwork` 等）：按效果图升级为同心虚线轨道、有光泽的渐变节点、带光晕的中心徽记。只在初始页出现；结果页不放插画（C2-6）。

## 2. 自适应布局

### 2.1 度量

- 在详情区根部用 `onGeometryChange`（macOS 13 起可用）测量宽和高，写入环境值 `PageLayout`。
- 宽度分档：
  - `compact` < 720；
  - `regular` 720–1039；
  - `wide` 1040–1499；
  - `extraWide` ≥ 1500。
  - wide 从 1040 起：默认窗口的详情区宽 1052–1084，要能拿到完整页头。
- 高度分档：
  - `short` < 560；
  - `regular` 560–899，其中 ≥ 680 才用完整页头和大插画；
  - `tall` ≥ 900。
- 要支持的最矮情形：窗口平铺成四分之一或半高时，详情区只有约 338 pt 高。这时页头收成紧凑形态，主操作放在贴底操作条里，始终可见。
- 档位边界留 16 pt 滞后，拖动窗口时不来回跳；切档时用 `standard` 动画。
- 各页不再自写 `GeometryReader` 断点。已有的 `ViewThatFits`、`WindowLayoutMetrics` 逐步并入 `PageLayout`：V0 并入样板页和共用组件，其余在 V1–V5。

### 2.2 窗口与侧栏

- **最小内容尺寸**：保持现值 820×520。工具栏占 52 pt，详情区实际只有约 468 pt 高。
  - 删掉现有“按 520 pt 最小高度排版”的做法。
  - 在任何高度下，关键内容和主操作都不能被裁掉：主操作进贴底操作条，其余内容滚动。
  - 状态条在矮窗口下并入贴底操作条或收起，不能只露半截。
- **侧栏两种形态**（取代现有按窗口宽 900 切换侧栏宽度的规则。旧规则下，窗口拉过 900 时详情区反而变窄）：
  - 窗口宽 ≥ 960：完整侧栏，宽 196–228 pt。
  - 窗口宽 < 960：自动收成约 64 pt 的图标栏，只显示图块；悬停显示名称提示；分组标题换成分隔线。
  - 用户手动展开或收起后，以用户选择为准，直到窗口再次跨过阈值。
  - 宽度变化有动画。
- 如果 `NavigationSplitView` 无法稳定实现图标栏，退回系统的自动收起（`.detailOnly`）加工具栏按钮，并在交接里写明原因。
- 侧栏顶部标题区固定，滚动内容在它下方渐隐。这同时修复首项被压的问题（D45 侧栏项）。

### 2.3 页头

| 条件 | 形态 |
|---|---|
| wide 或 extraWide，且详情区高 ≥ 680 | 完整页头：64 图块、26 pt 标题、副标题。初始页右侧放插画，占详情区宽 36–40%，高 ≤ 280；插画与操作卡垂直居中对齐，不贴顶 |
| regular | 52 图块、24 pt 标题。插画缩小到高 ≤ 200；正文需要宽度时隐藏插画 |
| compact，或详情区高 < 560 | 紧凑页头，约 52 pt：32 图块、20 pt 标题，不显示副标题。操作按钮保留，放不下时只留图标并加提示 |
| 详情区高 560–679 | 常规页头，不放大插画 |
| 内容向下滚动 | 页头随滚动收成紧凑页头并固定在顶部（`scrollTransition`／`visualEffect`）。减弱动态效果时直接切换 |

工具页（内存、能耗、性能等实时数据页）始终用常规或紧凑页头，不放大插画，把高度留给数据。

### 2.4 页面主体

- **`AdaptivePane`**：两栏比例约 58／42；regular 及以上并排，compact 改为上下排。
- **`AdaptiveCardGrid`**：每列最小宽 260 pt，自动排 1–4 列。
- **列表列优先级**：
  - P1 始终显示：图标、名称、大小；
  - P2 从 regular 起显示：类别、日期；
  - P3 从 wide 起显示：路径和附加信息。
  - 路径用中间省略，悬停显示完整路径。
- **`PinnedActionBar`**：用 `safeAreaInset` 固定在底部，主操作不随滚动消失；compact 下只显示图标和短标签。
- **extraWide**：
  - 正文最大宽 1400，居中，光晕铺满背景；
  - 卡片网格可以加列；
  - 不为大窗口新增功能面板。
- 文字段落的最大行宽约 720 pt。
- **中间尺寸不留空洞**：例如 1000×700。卡片和插画在可用高度里分布，操作卡与状态条之间不出现 150 pt 以上的空白；指标卡不排成 3+1 这类残缺行，改用 2+2 或 4 列。
- **整页不固定成视口高**：应用更新页现在被固定成视口高，又被放进居中容器，整页下移约 90 pt。这类写法改为正常的滚动与贴底操作条。

### 2.5 其他要适配的情况

V0 样板页全部覆盖，V1–V5 每页覆盖。

- **外观**：日间、夜间（纯黑／深空）、跟随系统。
- **语言**：中文、英文。英文更长，按钮和标签不能截成省略号；放不下就换行或缩写，并加提示。
- **数据状态**：
  - 空态、加载中、失败；
  - 极少数据；
  - 超多数据：一万行时滚动仍流畅，不卡主线程。
- **窗口**：侧栏展开或收起、全屏、分屏（窄而高）、外接 1× 显示器。
- **辅助功能**：减弱动态效果、降低透明度、增强对比度、VoiceOver 的顺序与标签。

## 3. 动效

### 3.1 令牌（`Support/AppMotion.swift`）

| 令牌 | 曲线 | 用途 |
|---|---|---|
| `hover` | easeOut 0.16 s | 悬停高亮、提示 |
| `press` | spring（response 0.22，阻尼 0.7） | 按下与松开 |
| `standard` | spring（response 0.38，阻尼 0.86） | 展开收起、切档、选中块移动 |
| `emphasized` | spring（response 0.55，阻尼 0.82） | 切页、结果出现、完成态 |
| `data` | easeInOut 0.7 s | 圆环、曲线、柱高、计数 |
| `stagger(i)` | 延迟 min(i, 12) × 0.035 s | 卡片和行依次出现，只排前 12 个 |

打开“减弱动态效果”时：
- 位移和缩放全部改成 0.2 s 淡入淡出；
- 循环动画停止；
- 计数直接跳到最终值；
- 滑动选中块直接到位。

### 3.2 场景

1. **切页**：新页淡入，同时上移 8 pt、缩放 0.995 → 1（`emphasized`）；旧页 0.15 s 淡出。背景光晕颜色渐变到新模块色。
2. **侧栏**：
   - 选中块在行间滑动（`matchedGeometryEffect`）；
   - 悬停时背景淡入；
   - 分组展开收起时箭头旋转 90°，行依次出现；
   - 完整侧栏与图标栏之间切换时宽度有动画。
3. **扫描**：
   - 开始按钮变形为进度卡：圆环扫过；
   - 当前阶段文字交叉淡入淡出；
   - 已发现大小用数字过渡递增；
   - 类别按完成顺序依次出现，插画节点逐个点亮；
   - 完成时圆环收满，对勾弹跳（`symbolEffect(.bounce)`），然后进入结果页。
4. **结果**：
   - 结论数字从 0 递增；分类卡依次出现；
   - 勾选框有动画；已选合计用数字过渡；分组展开收起有动画；
   - 行的增删用位移加淡出；
   - 清理完成后，已移走的行收起，释放量递增，完成卡弹入。
5. **数据**：
   - 圆环首次出现时从 0 画到当前值，之后从旧值过渡到新值；
   - 曲线的新样本从右侧推入；柱高用弹簧过渡；
   - 内存、能耗数值刷新用数字过渡。
6. **悬停与按压**：
   - 可点击的卡片悬停时上浮 2 pt，阴影或描边加强；
   - 列表行只高亮背景，不位移；
   - 按钮悬停提亮，按下缩放 0.97。
7. **弹层**：自绘浮层淡入并缩放 0.98 → 1；系统表单保持系统动画。
8. **加载**：列表和卡片用占位块加微光，1.2 s 一轮，不再只显示“正在采样…”文字。
9. **小窗**（V4 做，V0 不做）：打开、层级展开收起、数值过渡都有动画，但必须守住打开预算：热打开 100 ms、冷打开 250 ms、主线程阻塞 50 ms。

### 3.3 护栏

- 动画一律绑定 value：用 `.animation(_:value:)` 或 `withAnimation`，不允许无值的隐式 `.animation`。
- 超过 200 行的批量更新关闭动画（`transaction.animation = nil`）。“依次出现”只作用于前 12 项。
- **空闲时不跑循环动画**：
  - 初始页插画只在出现时播一次入场动画；
  - 循环动画只在扫描、测量等进行中运行；
  - 窗口不可见或被遮挡时暂停。
- CPU：初始页入场动画结束后，主窗口空闲 CPU ≤ 1%（采样 10 秒）。扫描中的动画开销单独记录。
- 动画期间不触发重型布局：插画用 `drawingGroup` 合成，列表行高度固定。

## 4. V0 批：设计基础与样板页

### 范围

- 令牌 v2（1.1–1.4）、`AppMotion`、`PageLayout`。
- 1.5 列出的组件。
- 侧栏：图块、滑动选中块、图标栏、顶部渐隐。
- `PageHero` 全局替换页头外观，所有页面先整体变好看一截；各页细节留到 V1–V5。
- 切页动画。
- 样板页做完整：
  - **智能扫描**：
    - 覆盖初始、扫描中（`--debug-scan-demo`）、结果三个状态；
    - 结果页按 D45／U3：一句话结论头、便当式分类卡，行内一句话说明加建议词（建议清理／谨慎／需人工判断）。
  - **内存管理**：
    - 包含总览、趋势、进程或可退出应用列表、退出确认入口；
    - 列表占满剩余高度；
    - 退出按钮用危险样式（N19、D49）。

### 不碰

- `ScanStore.swift` 和清理、执行的安全逻辑。
- 行为语义：预选、确认、执行规则（D47、D49、D52、N19）都不改。
- 文件分析与执行完成页（D46 批在改）。
- 小窗与设置窗口（V4）。
- 文案大改（V5）。

### 验收
