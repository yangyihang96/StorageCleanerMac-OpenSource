## 1. 用户要求

用户原话（10-22）：“接下来做空间地图：照 CleanMyMac 在气泡里放上应用和文件夹图标。”

## 2. 改了什么

- **气泡图标**：空间地图结果页（目录、最大的文件两种视图）的每个气泡，用该项自己的图标替换原来的通用选项图标。取法和左边列表一样：应用（路径以 `.app` 结尾）用它自己的图标，经 `CachedAppIconView` 缓存；文件夹用访达的文件夹图标；文件按扩展名用访达的类型图标，经 `SpaceLensKindIcon` 每种只取一次，不读文件本身。
- **大小**：`LightfieldBubbleLayout.pictureSide(diameter:labelled:)`。没有名字的气泡，图标约占直径的 62%；显示名字和大小的气泡（直径 ≥100），给两行文字留出位置。最小 12 pt，最大 56 pt。
- **范围**：`LightfieldChartItem` 新增可选的 `picture`（`LightfieldChartPicture`：路径＋是否文件夹），只有空间地图设它（`CareStudioSpaceLensPage.bubble(_:)`）。“文件类型”视图、合并的“其他 N 项”气泡、经典（D70）文件页和其他用气泡图的地方，都照旧用选项图标。原来那句 `LightfieldOptionIconView(icon: item.icon, pointSize: iconSide)` 保留着（源码约定锁着它）。
- 都没变：气泡的排布、悬停、点进文件夹、勾选文件、读屏文字；图表本体不带悬停状态。
