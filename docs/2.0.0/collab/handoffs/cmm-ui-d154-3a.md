## 2. 改了什么（都只用变换和透明度，不用序列帧；“减少动态效果”和测试截图里一律静止）

- **共享动效曲线**（`Support/AppMotion.swift`）：`arrival`（插画摆入）、`successPop`（成功弹出）、`tileArrival`（卡片升起）。Care Studio 只引用（UI 一致性规则不允许页面里直接写 `.spring(`）。
- **起始页插画摆入**（`CareStudioArt.entrance`）：从下方、略倾斜、略小、透明处摆入并轻微回弹，约 0.6 s，进入页面时一次；所有 Care Studio 起始页和模板起始页都开。运行页、完成页不摆入。
- **成功弹出＋光圈**：完成页的成功图从小弹到原大，同时两圈光向外扩散后消失（应用管理完成、垃圾清理完成、内存完成等用 `showsSuccess` 的地方都有）。
- **运行页光环**：工作中的插画背后一圈渐隐的光慢慢转（6 s 一圈），代替 CleanMyMac 的 Metal 极光，开销小；原有的浮动、摆动、拖影不变。
- **结果卡依次出现**：卡片区出现时每张晚 50 ms 淡入并升起 14 pt（第十张以后同时）。“已到达”状态放在卡片区而不是每张卡，卡片区布局时重建的卡片也能落位（窗口测试抓到过前两张没落位，已改）。
- **结果卡插画位**（`CareStudioTileModel.art`）：大卡（bento 左侧那张）中间放大插画，小卡右上角用插画代替符号圆，没给图的卡保持原来的符号；悬停时卡角物件轻微放大、倾斜。现在先用已有的模块图：重复文件、相似照片、浏览记录、应用更新、挑出用不到的应用、健康状态。D166 的物件到了按清单补齐其余的卡，不用再改结构。
