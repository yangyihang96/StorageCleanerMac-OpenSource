## 2. 改了什么

- **“运行”**（`SmartCareResultsPage`、`SmartCareCoordinator.run(cleanup:maintenance:)`）：
  - 性能卡在有建议的维护任务（维护任务页默认勾上的那些）时也有勾选框。
  - 点“运行”：勾了性能时，先问维护任务页的那句“运行选中的维护任务？”（每个任务写明做什么）。接着清理勾选的垃圾，走原有的计划、预检和确认单（黄/红勾选、D23 清空废纸篓两次确认、数量提醒、退出相关应用，一样不少）。确认单确认后执行清理，清理完成后再运行维护任务。
  - 在清理确认单上取消：什么都不跑，回到 5 张卡。
  - 清理执行途中被“停止”：已移走的留在废纸篓，维护任务不再运行（CleanMyMac 同样标“未运行”）。
  - 只勾了性能：只运行维护任务。
  - 运行中不能改模块选择，也不能“重新开始”或再点“运行”。
- **共用确认**：维护任务页的确认抽成 `View.maintenanceRunConfirmation(_:isPresented:run:)`，写在 `SystemMaintenancePage.swift`。维护任务页和智能扫描都调用它，文字和按钮原样。
- **页面**：
  - 清理时照旧显示预检、清理中的原有页面，确认单下面是 5 张卡。
  - 维护任务这一段显示新页 `SmartCareMaintenanceRunningPage`（性能颜色，当前任务名，不能中途停）。
  - 清理完、还有维护任务时，不先闪出清理自己的完成页。
- **完成页**：
  - 清理跑过：仍是原来的清理完成页；`SmartScanCleanupCompletedPage` 新增可选参数 `otherResults`（默认为空），在报告上方列出其他卡的结果，比如“性能：维护任务已运行完”“性能：没有运行（清理已停止）”。
  - 只跑了维护任务：用现有的终止页，写“运行完成”和结果行；有失败时用失败的样子。
- **“完成”回到起始页（顺带修第三批 K 的一处问题）**：
  - 原来在智能扫描里清理完点“完成”，只清掉了 5 张卡；而 `dismissV2CleanupReport` 会让 store 回到这次扫描剩下的行，于是退回了旧版的垃圾结果页。
  - 现在凡是结束一次智能扫描的“完成”，都会收起报告、清掉 5 张卡、清掉这次扫描的结果（`startOverV2Results`），回到起始页，和 CleanMyMac 运行完回到开头一致。
  - 从别处借用这一页的清理，完成后仍回到剩下的行。
- **都没变**：清理的计划、确认、执行、恢复、回执；维护任务的选择、执行顺序和租约（`.cleanup`，一次一个）；历史和菜单栏、小窗的数字。
