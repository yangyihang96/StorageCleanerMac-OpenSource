## 2. 改了什么

- **安全防护管理器**：安全防护结果卡片上的“查看”（和“查看所有记录”）现在进 CleanMyMac 式的浅色管理器面板，和垃圾清理、登录项、应用、杂乱文件管理器同一套：
  - 标题栏：返回（回到结果卡片）、标题“安全防护管理器”、搜索域名或页面、排序（最近访问、访问次数最多、按浏览器）。
  - 左栏：全部浏览记录（带条数）、每个浏览器（应用图标＋条数，点了只看这个浏览器）；“其他”下面是 Cookie 与其他数据（进原来的数据页）和最近的删除（原来的弹出面板，可恢复）；底部是读取覆盖情况和“读取状态”。
  - 右边：所选范围的标题和一句规则说明；时间（今天、最近 7 天、全部）、全选、反选、批量选择；下面是原来的浏览器→配置文件→站点→页面行（敏感网站照旧打码折叠、展开要审阅），刷新状态、完全磁盘访问提示、运行中浏览器提醒、处理进度和处理报告、空状态都还在原位置。
  - 底栏：左边“更多”（重新扫描、取消选择）和“筛选”（配置文件、类别、置信度、日期、清除），中间已选数量，右边粉色“删除”；所选只能在浏览器里处理时按钮变成“在浏览器内处理”。
- **安全步骤一个没动**：删除前的确认（六项事实＋备份说明）、浏览器仍在运行的确认（正常退出并继续／跳过）、全选和批量选择的确认、创建恢复备份、删除后回读核验、手动处理说明都还是原来的，弹窗仍挂在 `BrowserPrivacyRecordResultsView` 上；管理器只是同一个视图的另一种外观（`presentsManager`）。经典版式（测试的 `careStudioClassicResults`）仍是 D67 页面。
- 结果索引在扫描时一次算好每个浏览器的记录条数（`recordCountByBrowser`），左栏不必每次刷新都遍历全部记录。
- **软件用自己的图标**：
  - 浏览器（安全防护管理器左栏、记录列表的浏览器/配置文件行、D67 行、“Cookie 与其他数据”页每一行）显示 Safari、Chrome 等的真实图标：优先用扫描找到的应用，找不到再按 bundle ID 问 Launch Services（只取图标，`BrowserPrivacyBrowser.iconPath`），都没有才退回模块符号。
  - 聊天文件左栏的微信、QQ、企业微信显示各自应用图标（按 bundle ID，没装就用原符号，`ChatApp.iconPath`）。
  - 结果卡片：安全防护“N 个浏览器正在运行”卡角显示正在运行的浏览器图标；杂乱文件“聊天文件”卡在读到数据后显示聊天软件图标（小卡原本就是“有应用图标先用应用图标，否则用 3D 物件”）。
  - 管理器和工具面板的左栏行都支持应用图标（`CareStudioManagerCategoryRow.appIconPath`、`ToolboxCategoryRow.appIconPath`）。
  - 云盘清理的“其他云盘”只记录了文件夹名和路径、没有 bundle ID，要靠猜映射，这次没动。
- **管理器标题栏**：窄窗口（604×490 等）里居中的标题会压住右边的搜索框（所有管理器都有）。改为小布局 `CareStudioManagerHeaderLayout`：能居中就居中，放不下时挪到返回和搜索之间的空位、再不够就截断；共用外框和垃圾管理器的标题栏都用它。
- “Cookie 与其他数据”的标题原来是 `static let`，第一次读取时就固定成当时的语言（中英切换后不更新），改成每次按当前语言取。
- **修正**：结果卡片“敏感网站”原来只数成人内容，但列表默认打码折叠的是成人和金融两类，卡片说“条记录默认折叠”数少了；改为同一规则（`BrowserPrivacyLightfieldPresentation.isSensitive`），测试同步改。
