## 2. 改了什么

- **空间地图结果页**（`CareStudioSpaceLensPage`，新文件 `CareStudio/CareStudioSpaceLens.swift`）：原来是 D70 的“文件分析”页（标题和侧栏不一致、底部长条按钮），改成 CleanMyMac 空间透镜的版式：
  - 顶部：返回上一层、路径（根目录和最近两层，每层可点回去）、“更多”菜单（更换范围、容量口径、本地 AI 模型、设备备份、云文件本地副本、选择与操作详情）；读取目录时的提示和“重试”也在这一行。
  - 用量条：“已用 X / 共 Y”，所选部分在已用里用白色标出，旁边是已选和可用；下面一行是当前文件夹、大小和容量口径说明。
  - 左边半透明列表：目录 / 文件类型（圆环图）/ 最大的文件三种视图；每行勾选框（或锁、核对中）、图标、名称和占比条（最大的文件显示路径）、大小和百分比，文件夹可进入；右键快速查看、在访达中显示、复制路径。
  - 右边大气泡图（原来的气泡图，悬停与列表互相高亮，点文件夹进入、点文件勾选；文件类型视图下点类型高亮）。
  - 底部圆按钮“移除”：先打开原来的审阅（`FileAnalysisTrashReviewSheet`），确认后才移到废纸篓；按钮上方是原来的状态行（已选、提示、上一次结果）。
- **图标**：应用用它自己的图标；文件夹用访达的文件夹图标，文件按扩展名用访达的类型图标（每种只取一次，不读文件本身）。
- **都没变**：只用已完成的索引、不重新遍历；勾选规则（所选文件夹里的项目算作已含、系统/受保护项目锁定、核对中）、审阅与确认、废纸篓与操作记录、各个说明和盘点表单都还是原来的，挂在 `FileAnalysisLightfieldView` 上；经典版式（测试的 `careStudioClassicResults`）仍是 D70 页面，原有源码约定全部照旧。
- 演示夹具（`FeatureLightfieldFileResultFixture`）在 Care Studio 版式下也显示新页面；D67 文件页的窗口测试改为显式设经典版式。
