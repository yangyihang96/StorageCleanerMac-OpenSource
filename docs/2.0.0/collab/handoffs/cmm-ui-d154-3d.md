- **内存结果页**：原来五行数字表＋“查看占用最多的应用”胶囊按钮，改成四张带 D166 物件的小卡（2×2）：空闲内存（内存条，前→后，下面一行文件缓存前→后）、内存压力（压力表，前→后，下面一行用时）、压缩内存（芯片，前→后）、占用最多的应用（应用方块，整张卡是按钮，进原来的应用列表，“退出前会先确认”）。数字和原来的表逐项相同，一个都没少。宽度够时两列，窄窗口一列（数字不缩小、不截断；UI 一致性规则不允许这里用 `minimumScaleFactor`，按钮用共用的 `CareStudioRowButtonStyle`）。没有实际推送（无需释放、压力已升高、已取消）时只出“占用最多的应用”一张卡。页面高度不到 460 pt 时完成图移到标题左边（604×490 窗口四张卡不用滚动就全露出）；最小窗口仍放不下时整页在原地滚动，圆按钮始终在窗口内（和清理完成页同一做法）。卡上物件悬停时略放大倾斜（同结果卡，减少动态效果时不动）。
- **状态图**（D166 的空盒、全部正常盾牌、锁、警示牌）：保持图本身的颜色，不转成模块色（`GeneratedArt.keepsOwnColour`；其余图仍按实测色相精确换色）。接到：
  - 结果卡片页标题上方：杂乱文件“没有找到内容完全相同的文件”（且没有人工候选）→ 空盒；安全防护“没有读到浏览记录”→ 缺完全磁盘访问时锁、部分读取时警示牌、其余盾牌；云盘清理“这台 Mac 没有启用 iCloud 云盘”→ 空盒、“文件都只在云端”→ 盾牌。
  - 聊天文件缺完全磁盘访问的起始页：模块图换成锁（起始页模板新增可选 `art`）。
  - 管理器空分类（新组件 `CareStudioManagerEmptyState`：图＋一句话）：登录项管理器“没有符合条件的项目”、应用管理器各分类的空说明（可疑为盾牌，其余空盒）、杂乱文件管理器某类为空或搜索无结果、垃圾管理器搜索无结果、扩展“没有找到第三方扩展”／某类为空／系统扩展列表读取失败（警示牌）、聊天文件“没有找到微信、QQ 或企业微信的文件”／筛选无结果（左栏原来那行重复的提示去掉）。
  - 安全防护记录列表的空状态：筛选无结果空盒、需要授权锁、部分读取警示牌、没有记录盾牌（读取中仍是转圈）。
  - 维护任务、扩展、聊天文件操作完成后的提示：成功用对勾硬币、没做成或没全做成用警示牌（`ToolboxNotice.showsStateArt`，其他提示不变）。
