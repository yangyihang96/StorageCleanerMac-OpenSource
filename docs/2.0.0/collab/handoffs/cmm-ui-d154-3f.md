## 2. 改了什么

- **Cookie 与其他数据管理器**：安全防护里的“Cookie 与其他数据”（结果卡片、管理器左栏都能进）改成和聊天文件、扩展、维护任务同一套浅色工具面板：
  - 标题栏：返回（回到浏览记录）、标题、按网站或个人资料筛选。
  - 左栏：五个数据类别（Cookie、站点存储、下载记录、表单自动填充、最近关闭的标签与窗口），各带 D166 物件和条数（没读取时写“未读取”）；类别前的勾只选这一类里能删的项目。
  - 右边：类别标题和它的限制说明，读取中提示、读取消息、各浏览器不能删的原因，下面每一行是一个浏览器配置文件的一个站点（或列表）：浏览器图标、站点、浏览器 · 配置文件、条数；不能删或站点在保留列表里时显示锁（悬停说原因）；站点行右边有“保留”。
  - 底栏：左边“更多”（读取/重新读取、保留的站点…、最近的删除、取消选择），中间已选数量，右边粉色“删除”。
  - 没读取时右边是空状态和“读取”按钮（和原来一样要手动读取，不自动读浏览器数据）。
- **流程不变**：删除前的确认（Cookie 会提示“将退出这些网站的登录”、先备份）、最近的删除（可恢复）、保留站点规则（保护子域和对它生效的父域 Cookie）都还是原来的；保留列表改成一个面板（“保留的站点…”），可移出。经典版式（测试的 `careStudioClassicResults`）仍是原来的 D91 页面。
- `BrowserPrivacyDataView` 可以传入数据 Store（测试和截图用），默认照旧自己建。
- 工具面板（聊天文件、扩展、维护任务、这一页）的标题栏也换成第三批 E 的避让布局，窄窗口里标题不再压住搜索框；左栏行支持 D166 物件（`ToolboxCategoryRow.art`）。
