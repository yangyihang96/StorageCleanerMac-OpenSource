# D67「光场」实现规范

用户 10-08 选定方向 1「光场」，并认可可交互原型（https://claude.ai/artifact/BkYjgZZ5F7Hvzn7b8LaDGS ，源码副本见 `.sc-build/r2-lightfield-r1/reference/lightfield-prototype.html`）。本文把原型定成数值，作为 SwiftUI 实现与验收的唯一标准。数值以 1280×763 窗口为基准；其他尺寸按“自适应”一节换算。

## 1. 一副骨架，三种状态

所有功能（14 个）共用同一骨架。起始、运行、结果三态之间只换内容，骨架元素不移动。

| 元素 | 位置与尺寸（画布坐标，原点为侧栏右侧、标题栏下方；画布 1070×735） | 三态行为 |
|---|---|---|
| 标题 | x 96，y 92，34 pt 粗体，字距 +0.01 em | 始终同位；切换功能时淡出淡入 180 ms |
| 内容区 | x 96，y 176，宽 520，高 395 | 结果态宽度扩展到画布宽 − 192（基准 878） |
| 主按钮 | x 96，y 595，520×52，圆角 12 | 始终同位同尺寸；只换文字：开始扫描／开始检查 → 取消 → 结果主操作 |
| 底部状态行 | 左右内缩 52，高 64，顶部 1 pt 细线 | 左：状态（尚未扫描／扫描中 · 64%／已选 3 项 · 12.2 GB）；右：一行安全提示，前有 1 pt 竖线 |
| 主插画 | 起始／运行：x 610，y 150，360×360；结果：x 96，y 176，76×76（摘要区） | 见动效 |
| 光晕 | 起始／运行：直径 640，中心与插画中心一致；结果：直径 420，移到摘要区左侧并减弱到 0.6 倍 | 见动效 |

不使用卡片框、磨砂底块或描边容器（D63/D66）。分隔只用 1 pt 细线（颜色 `hair`）。

## 2. 内容区各态

- 起始：分区标签（13 pt，`fg2`，字距 +0.02 em）→ 14 pt 间距 → 顶部细线 → 选项行。选项行高 56，底部细线，左侧勾选框 20×20 圆角 6（未选 1.5 pt `fg` 35% 描边；选中填充 `accent`，白色对勾，对勾弹出 160 ms 回弹曲线 (0.3,1.6,0.5,1)），文字 16 pt；行尾可有一个 13 pt `fg3` 的元数据（如“超过 30 天”“未安装”）。悬停整行底色 `hover`。
- 运行：标签（扫描中／检查中）→ 大数字百分比 64 pt 粗体等宽数字，单位“%”24 pt `accent` → 22 pt 间距 → 进度条高 4 圆角 2（底 `hair`，填充 `accent2→accent` 渐变并带 12 pt `accent` 外发光）→ 22 pt 间距 → 三行事实 15 pt `fg2`（当前阶段；已发现 **8.4 GB**；3 / 4），数值部分 `fg` 粗体。
- 结果：摘要区高 76（插画 76×76 + 右侧：结果标签 13 pt + 总量 52 pt 粗体，单位 24 pt `accent`）；摘要区下方 20 pt 起为列表，顶部细线，列表在主按钮上方 24 pt 处结束，超出时在区内滚动（细滚动条）。
  - 勾选型行：高 52，四列：勾选框 20 | 名称（弹性 1.2）| 路径或说明（弹性 2，等宽 12.5 pt `fg3`，单行截断）| 大小（96，右对齐等宽）。
  - 状态型行（系统健康等）：首列为状态符号 20×20（正常绿色圆形对勾、警告琥珀三角、失败红色），末列为状态文字并着同色；不可勾选。状态符号属于信息，不是装饰（D64）。

## 3. 动效

| 事件 | 动画 | 时长与曲线 |
|---|---|---|
| 点“开始” | 按钮按下缩放 0.985；起始层淡出并上移 10 pt；运行层淡入 | 按下 120 ms；层切换 240 ms 淡出、260 ms 位移，曲线 (0.2,0.8,0.2,1) |
| 运行中 | 光晕呼吸（透明度 +0.25、缩放 1.06），插画上下浮动 6 pt | 光晕 1.8 s、插画 2.4 s 循环，ease-in-out |
| 扫描完成 | 插画从右侧飞入摘要区并缩到 76；光晕同步移动缩小；内容区宽度展开 | 560 ms，(0.2,0.8,0.2,1)，三者同时 |
| 结果出现 | 列表逐行淡入并上移 8 pt；总量从 0 数到结果 | 每行 300 ms，行间隔 40 ms，首行延迟 380 ms；数字 640 ms ease-out cubic |
| 勾选变化 | 对勾弹出；状态行与按钮可用性即时更新 | 160 ms |
| 切换功能 | 标题淡出淡入；插画淡出缩至 0.94 再淡入；主题色过渡 | 标题 180 ms；插画 260 ms 透明度 + 320 ms 缩放；颜色 300 ms |
| 减少动态效果 | 全部改为即时切换，关闭呼吸与浮动 | — |

## 4. 颜色

| 侧栏 | #0A0F24，分隔 白 6% | #E8EEF8，分隔 #162850 8% |
| `fg` / `fg2` / `fg3` | #F2F5FF / #A8B2CC / #6F7A96 | #121A33 / #4F5B78 / #7E889F |
| `hair` / `hover` | #BAC8FF 12% / 白 4% | #162850 12% / #162850 4% |
| 星尘 | #D2DCFF 55%，约 90 点，随机透明度 | #4664B4 18% |

功能主色 `accent / accent2`：智能扫描 #4F8BFF/#2A55D6；安全清理 #FF7A2F/#C4441A；开发工具 #FFB340/#C46A0C；系统健康 #34C77B/#1E9E5A；浏览器隐私 #2FBF71/#168A55；内存管理 #8B6CFF/#5B3FD9；卸载 #A07BFF/#5B3FD9；重复文件 #2CC9D6/#0E7C8C；其余功能沿用现有主色。

主按钮：`accent`（混 8% 白）→ `accent2` 竖向渐变，1 pt `accent` 70% 描边，外阴影 `accent` 35% 偏移 10、模糊 30，内顶高光白 25%；“取消”态为透明底、`accent` 80% 描边、`fg` 文字。

## 5. 字体

系统字体（SF Pro / 苹方）。层级只用：34 粗（标题）、64／52 粗（大数字）、24 半粗（单位）、17 半粗（主按钮）、16（选项）、15（列表与事实）、13（标签、状态行、元数据）、12.5 等宽（路径）。数字一律等宽数字。

## 6. 插画与侧栏图标

主插画用已批准的风格 A 生成插画（`Resources` 现有资源，与 `.sc-build/art/set-A` 同源）。侧栏导航图标改用同一套插画的 20×20 缩略版，使全软件只有一种拟物风格（D67、D64：侧栏可点击，保留图标）。如有功能缺图，用 Codex 按 `.sc-build/art/set-A/prompt.md` 风格补生成，不混用 SF Symbols 彩色方块。

## 7. 自适应

- 内容区宽度 520，窗口变窄时最小 360；插画尺寸在 240–420 间随可用宽度变化，且始终在内容区右侧不重叠。宽度不够同时放下时（详情区宽 < 760），插画缩到 160 并移到标题右侧。
- 竖向：骨架整体在画布内垂直居中，标题顶部不少于 48；主按钮与状态行之间保持 24。高度不足时内容区内部滚动，主按钮与状态行不被挤出。
- 结果态列表在任意尺寸下都在主按钮上方结束，只在区内滚动。
- 验收尺寸沿用七尺寸矩阵（820×560、1000×700、1280×763、1680×1050、2400×1350、677×390、1280×390）。

## 8. 验收

1. 同状态并排对照：实现截图与原型（同功能、同状态、同主题、1280×763）逐项比较，位置误差 ≤ 2 pt，颜色与原型令牌一致。
2. 几何断言：14 个功能三态的标题、内容区起点、主按钮、状态行位置尺寸相等（误差 0.5 pt）。
3. 源码检查：结果页与起始页不得使用磨砂材质、卡片背景或装饰图标。
4. 动效：时长与曲线由单一常量表提供，测试锁定数值；减少动态效果时为即时。
5. 覆盖 `.sc-build/r2-redesign/acceptance-checklist.md` 全部条目。
