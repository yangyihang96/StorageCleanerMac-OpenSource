# 存储清理助手 / Storage Cleaner Mac

**当前版本 / Current version:** `1.9.13`

存储清理助手是一款原生 macOS SwiftUI 应用，用来把本机磁盘占用、可自动清理、大文件、重复文件、应用残留、启动项、程序升级和内存状态放到一个可复核的界面里。它强调“先看清楚，再决定处理”，扫描阶段保持只读，清理动作需要用户明确确认，并优先移到废纸篓。

Storage Cleaner Mac is a native macOS SwiftUI app that brings storage usage, auto-clean items, large files, duplicate files, app leftovers, startup items, app updates, and memory status into one review-first interface. It is designed around a clear safety boundary: scans are read-only, cleanup actions require explicit user confirmation, and removable items are moved to Trash first whenever possible.

## 它基于什么实现 / What It Is Based On

- **Swift Package Manager**：项目是 SwiftPM-first 的 macOS 应用，入口是 `Package.swift`，常规构建和验证脚本位于 `script/`。
- **SwiftUI + AppKit**：主界面使用 SwiftUI 构建，窗口、菜单、本地化、Finder 定位和系统设置跳转等 macOS 行为通过 AppKit/NSWorkspace 衔接。
- **Apple 本地文件系统 API**：扫描和清理基于本机文件系统、`FileManager`、`NSWorkspace`、用户废纸篓以及 macOS 系统设置 URL；清理功能不依赖云端。查看全球榜单会发起只读请求；只有用户明确确认发布符合资格的 V7 成绩时，才会向排行榜服务写入数据。
- **只读扫描模型**：扫描阶段只读取路径、大小、类型、权限状态和元数据，不会自动删除、移动或修改文件。
- **1.9.1 固定尺寸分层监控小窗**：极客模式成为同一 Panel 体系的完整母版，详细模式复用完全相同的结构、交互和数据源，只减少扩展字段；简单模式继续保留最少信息。一级概览固定为紧凑的 301 × 553 点组合视图，CPU、内存压力、磁盘、网络、传感器和电源按固定顺序快速扫读；鼠标悬停后才展开对应二级明细，逐项悬停继续显示三级趋势或设备信息。网络页新增真实逐进程上传/下载速率、接口、Wi-Fi、本地/公网地址和只读诊断状态；温度、风扇、电池与功耗使用真实可用传感器并明确不可用状态。小窗点击外部自动关闭，设置入口收敛到暂停、刷新和更多操作，面板不会自由缩放。

## 安全边界 / Safety Boundary

- 扫描是只读的。
- 不会在后台自动清理。
- 不会为了扫描自动申请媒体库权限。
- 绿色项目也会先移到废纸篓，清空废纸篓后才真正释放空间。
- 黄灯、红灯、云盘、本体应用、聊天记录、媒体库和敏感路径需要人工复核。
- 打开 Finder、打开废纸篓、复制清单、导出报告、打开系统设置都只是辅助动作，不代表已经清理、授权、卸载或更新。

- Scans are read-only.
- The app does not run cleanup in the background.
- It does not request media-library access just for scanning.
- Even green items are moved to Trash first; disk space is truly freed only after Trash is emptied.
- Yellow/red items, cloud folders, app bundles, chat records, media libraries, and sensitive paths require manual review.
- Finder reveal, opening Trash, copying lists, exporting reports, and opening System Settings are helper actions only; they do not mean cleanup, authorization, uninstall, or update has completed.
