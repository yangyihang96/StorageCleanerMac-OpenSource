# XCTest classes that can put a window or system UI on screen (DECISIONS
# D106). Checked by script/display_bound_tests.py, which script/verify.sh
# runs (exit 17): every class the scanner detects must be listed here once,
# and every listed class must still be detected and exist in
# Tests/StorageCleanerMacTests, so the list cannot drift.
# verify.sh has no display to confine windows to: it skips the in-process and
# out-of-process classes and prints them as NOT RUN.
# script/run_display_bound_tests.sh runs the in-process classes with
# STORAGE_CLEANER_TEST_DISPLAY set, so the test bundle's display gate places
# every window on that one named non-main display before it is shown.
# Format: Class | kind | reason
#   in-process      skipped by verify.sh, run by run_display_bound_tests.sh
#   out-of-process  skipped by verify.sh and never run by the display runner:
#                   it launches another app, whose windows the gate cannot place
#   exempt          detected, but runs in verify.sh because it shows nothing;
#                   the reason must say why
# Exempt entries for the display gate's own tests are added with those tests.
