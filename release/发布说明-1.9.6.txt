存储清理助手 1.9.6

界面与性能：

- 性能测试成为独立一级入口，继续按一次点击依次完成 CPU、图形与媒体、持续性能测试，不重复实现测试引擎。
- 小窗概览重新显示当前风扇模式和能源模式；只读取系统已有能力与真实状态，不生成虚假的硬件数据。

清理功能：

- 清理流程升级为“扫描快照 → 用户选择 → 冻结清理计划 → Preflight → 用户确认 → 废纸篓或隔离区 → 执行验证 → 清理报告”。
- 清理前会重新检查路径边界、文件身份、文件类型、符号链接、卷身份、写入权限、云文件状态、用户排除项和相关应用运行状态。
- 执行中单个项目失败不会扩大清理范围；成功、跳过、失败和取消后未处理项目分别报告。
- 安全取消只在项目边界生效，当前正在进行的 macOS 废纸篓移动会先完成或返回错误。
- 清理计划在确认前冻结，同一计划最多执行一次；重新扫描或规则变化后旧计划失效。
- 支持移入 macOS 废纸篓或 App 专用隔离区。两种方式都不执行永久删除，并提供基于文件身份的安全恢复。
- 恢复时不会覆盖原位置已有文件；隔离项目被替换、路径越界或符号链接发生变化时会拒绝恢复。
- 清理报告分别显示已移动体积、清空废纸篓后可能回收的估算体积、执行前后观测到的可用空间变化和实际永久释放空间。本流程不清空废纸篓，因此实际永久释放空间为 0；可用空间变化可能同时受系统活动影响。

兼容与迁移：

- 首次进入 1.9.6 清理功能时，会幂等迁移 1.9.5 的扫描排除路径；旧键和旧扫描、清理、恢复记录保持不变。
- 旧扫描结果、待确认项目和文件级选择不会迁移；升级后需要重新扫描。
- 规则、迁移或执行门禁校验失败时会关闭 V2 执行，不会回退到 1.9.5 清理器。

安全边界：

- 普通清理不会调用永久删除，也不会使用特权辅助程序。
- 浏览器数据、应用本体、用户文档、云盘根目录和未知项目不会进入普通清理计划。
- 系统废纸篓 API 仍以路径为输入。1.9.6 使用两次文件身份检查、串行执行和移动后回执降低竞态风险，但不宣称路径移动完全原子。
- 本机发布签名仍为 Apple Development，不是 Developer ID Application，也没有 Apple notarization；不得描述为公证版或 public-safe。
