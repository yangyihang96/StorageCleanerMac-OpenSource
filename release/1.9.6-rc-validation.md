## RC2 阻断与 RC3 修复

RC2 在真正 VM 的首次 V2 扫描中发现了真实迁移缺陷：`ScanStore.currentV2ExcludedURLs()` 将已清洗的 V2 排除项与原始 legacy 排除项重新合并，使无效的 `/Users/admin` 被重新引入，并把整个 VM 用户主目录排除，导致扫描结果为 0 B。

RC3 在唯一共享入口修复根因：

- V2 与 legacy 排除项统一进入 `CleanupMigration.v2ExcludedURLs(defaults:userHomeURL:)`；
- 仅接受绝对路径；
- 拒绝用户主目录本身；
- 拒绝主目录外路径及相对路径；
- 仅保留主目录内后代路径；
- 去重并稳定排序；
- `ScanStore` 不再二次拼接未清洗的 legacy 值；
- 回归测试覆盖主目录、相对路径、主目录外路径、重复路径及迁移后新增合法排除项。

修复提交：`f19a817 fix: validate migrated cleanup exclusions`。

RC3 首次真实扫描重新发现缓存、日志、Derived Data 和下载文件，证明修复进入 Release 产品。
